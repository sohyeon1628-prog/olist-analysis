# Olist 첫 구매 고객 분석: 배송·리뷰 경험과 재구매

브라질 이커머스 Olist 공개 데이터로 **첫 구매 경험(배송 지연, 리뷰)과 180일 재구매의 관계**를 확인한 프로젝트입니다.
결과를 보기 전에 판단 규칙(계획서 v1.2)을 먼저 정하고, 그 규칙대로만 결론을 내렸습니다.

- 탐색 화면: https://sohyeon1628-prog.github.io/olist-analysis/
- 분석 이야기(케이스 스터디): https://sohyeon1628-prog.github.io/olist-analysis/story.html

## 개요
- **대상**: 2017-01 ~ 2018-02 첫 구매 고객 55,261명
- **결과 지표**: 첫 구매 후 180일 안의 재구매 (전체 1.95%, 1,080명)
- **질문**
  1. 배송이 늦으면 부정 리뷰(1~2점)가 늘어나는가?
  2. 배송이 늦은 고객은 재구매가 줄어드는가?
  3. 부정 리뷰를 남긴 고객은 재구매가 줄어드는가?
- **판단 규칙**: p < 0.05 이고, 재구매 비교는 그룹마다 재구매 고객 10명 이상일 때만 "차이 있음"

## 결과

| 질문 | 비교 | 결과 | 판정 |
| --- | --- | --- | --- |
| ① 지연 → 부정 리뷰 | 지연 65.4% vs 정시 9.5% | 6.9배, p < 0.001 | **차이 있음** |
| ② 지연 → 재구매 | 지연 1.61% vs 정시 1.98% | -0.37%p (95% 구간 -0.80 ~ +0.05%p), p = 0.12 | 차이 없음 |
| ③ 부정 리뷰 → 재구매 | 부정 1.68% vs 긍정 2.01% | -0.33%p, p = 0.061 | 차이 없음 |

- **"차이 없음"은 "영향이 없다"가 아닙니다.** 재구매가 워낙 드물어서, 이 표본으로 확실히 잡아낼 수 있는 차이는 ②에서 약 0.7%p(상대 34%) 이상입니다. 그보다 작은 차이는 있어도 놓칠 수 있습니다.
- ③은 기준에 가까운 경계선 결과입니다. 미리 정한 규칙대로 "차이 없음"으로 판정했습니다.
- 카테고리, 구매 월, 결제 금액을 함께 넣은 로지스틱 회귀에서도 ②③은 같은 결론이었습니다.
- 모든 결과는 **관계**이고 원인이 아닙니다. 원인은 A/B 테스트로 확인해야 합니다.

### 불만 주제 (글이 있는 부정 리뷰 5,395건, 미리 정한 포르투갈어 단어 사전)
- 지연 고객 부정 리뷰의 **51.8%가 "아직 못 받았다"(미수령)** 는 내용
- 정시 고객은 일부 누락 13.2%, 품질·파손 10.6%, 설명과 다름·오배송 10.4%

### 계획에 없던 탐색 (가설로만 다룸)
- **리뷰 작성 시점**: 지연 고객의 **76.5%가 상품을 받기 전에** 리뷰를 작성. 지연 고객의 부정 리뷰 비율은 받기 전 작성 77.2%, 받은 뒤 작성 27.2% (정시 고객 9.5%)
- **리뷰 글 감성 (BERTimbau)**: 다른 브라질 쇼핑몰(B2W) 리뷰로 학습한 포르투갈어 언어 모델로 글의 감성을 분류
  - 정확도 98.2% (별점을 가리고 글만 보고 판정한 정답 400건 기준, 같은 리뷰를 별점만으로 판정하면 96.4%)
  - ★4~5인데 글이 부정 8.1%, ★1~2인데 글이 긍정 5.4%
  - 리뷰에 글을 남긴 첫 구매 고객만 보면 부정 고객의 재구매율이 조금 낮음(1.77% vs 2.16%, p = 0.048). 결과를 본 뒤 추가한 분석이라 결론은 바꾸지 않음

### 제안 (실험으로 확인할 것)
1. 리뷰 요청을 배송 예정일이 아니라 **실제 도착 후**에 보내기
2. 지연이 예상되면 고객보다 먼저 알리기
3. 재구매는 구매 주기(중앙값 59일)에 맞춘 리마인드로 따로 설계
4. 불만을 글로 남긴 고객에게 먼저 응대하기

## 폴더 구조
```text
olist-analysis/
├── docs/                       # GitHub Pages
│   ├── index.html              # 탐색 화면: 구매 → 결제 → 배송 → 리뷰 → 재구매 단계별 추이·분포, 리뷰 원문
│   ├── story.html              # 분석 이야기 (결과·판정·제안·한계)
│   └── data/                   # 조회용 데이터 (orders.js, reviews.js)
├── results/
│   ├── summary.md              # 결과 상세 (규칙 v1.2)
│   ├── *.png, *.csv            # 그래프, 표, 불만 주제 표본 리뷰
│   ├── review_ko.json          # 리뷰 한국어 번역 (일부, Claude)
│   └── sentiment/              # 감성 분석: 판정 기준, 정답 세트, 모델 설정, 결과 요약
├── analyze.py                  # 규칙 v1.2 분석
├── build_explorer.py           # 조회용 데이터 생성
├── translate_reviews.py        # 번역 묶음 합치기
├── sentiment_*.py              # 감성 분석 (정답 세트 추출 · 모델 학습/판정 · 결과 정리)
└── requirements*.txt
```

## 실행
```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
# Kaggle 원본 CSV 9개를 data/raw/ 에 넣은 뒤
.venv/bin/python analyze.py          # 결과 · 그래프
.venv/bin/python build_explorer.py   # 탐색 화면 데이터
```
감성 분석은 `requirements-sentiment.txt`(PyTorch, transformers)와 B2W 리뷰 데이터가 따로 필요하고, GPU 없는 맥에서 약 1시간 걸립니다.

## AI 활용
분석 코드, 웹 화면, 리뷰 번역, 감성 분석 정답 세트 판정은 AI(Claude)와 함께 작업했습니다.
정답 세트는 사람이 50건을 따로 판정해 일치율(86.7%, 카파 0.77)을 확인했습니다. 화면의 숫자는 모두 원본 데이터에서 코드로 계산한 값입니다.
