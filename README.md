# Olist 첫 구매 고객 경험 및 재구매 분석 (Olist Customer Retention Analysis)

브라질 이커머스 플랫폼 Olist의 공개 데이터를 바탕으로 **"첫 구매 경험(배송 지연, 리뷰 만족도)이 고객의 180일 재구매에 미치는 영향"**을 가설 검증하고, 이를 직관적으로 탐색할 수 있는 인터랙티브 웹 대시보드와 케이스 스터디를 제작한 프로젝트입니다.

* 🌐 **데이터 탐색 대시보드:** [https://sohyeon1628-prog.github.io/olist-analysis/](https://sohyeon1628-prog.github.io/olist-analysis/)
* 📖 **분석 이야기 (케이스 스터디):** [https://sohyeon1628-prog.github.io/olist-analysis/story.html](https://sohyeon1628-prog.github.io/olist-analysis/story.html)

## 📌 분석 개요
* **분석 대상:** 2017년 1월 ~ 2018년 2월 첫 구매 고객 55,261명
* **핵심 지표:** 첫 구매 후 180일 이내 재구매 여부 (전체 재구매율 1.95%, 1,080명)
* **주요 질문:**
  1. 배송 지연을 겪은 고객은 부정적인 리뷰를 작성할 가능성이 높은가?
  2. 첫 구매 시 배송 지연을 겪은 고객은 재구매율이 떨어지는가?
  3. 첫 구매 시 부정적인 리뷰를 남긴 고객은 재구매를 하지 않는가?

---

## 📊 핵심 분석 결과

### 1. 배송 지연 → 부정 리뷰 (1~2점) : 유의미한 차이 ✅
* **지연 고객의 부정 리뷰율:** 65.43% (vs 정시 고객 9.49%)
* **결과:** 지연 고객이 부정 리뷰를 남길 확률은 정시 고객 대비 **약 6.9배** 높음 ($\chi^2$ 검정 $p < 0.001$).
* **불만 주제 분석:** 지연 고객 부정 리뷰의 51.8%는 "미수령" 상태에서 작성됨.

### 2. 배송 지연 → 180일 재구매율 : 차이 없음 (통계적 유의성 없음) ❌
* **지연 고객 재구매율:** 1.61% (59명 / 3,671명)
* **정시 고객 재구매율:** 1.98% (1,021명 / 51,588명)
* **결과:** 차이 -0.37%p ($p = 0.12$). 우연의 범위로, 배송 지연 자체가 재구매 단절의 결정적 단일 원인으로 작용하지는 않음.

### 3. 리뷰 평점(부정 vs 긍정) → 재구매율 : 차이 없음 ❌
* **부정 리뷰 고객 재구매율:** 1.68% (121명 / 7,209명)
* **긍정 리뷰 고객 재구매율:** 2.01% (861명 / 42,853명)
* **결과:** 차이 -0.33%p ($p = 0.061$). 리뷰 평점과 재구매율 간에도 통계적으로 유의한 차이가 관찰되지 않음.

### 4. 사후 발견 (탐색적 분석) & 제언 💡
* **발견:** 배송 지연 고객 중 **76.5%는 상품이 실제로 도착하기 전에 리뷰를 작성**했습니다.
* **마케팅/운영 제언:**
  * 배송 관리는 '재구매 유도'보다는 **신규 고객 유입의 핵심 통로인 리뷰 평점 관리(브랜드 신뢰)** 관점에서 접근해야 합니다.
  * 리뷰 요청 메시지를 '예상 배송일' 기준이 아닌 **'실제 배송 완료 API 신호'** 기준으로 발송하도록 프로세스를 개선하여 불필요한 부정 리뷰 양산을 방지해야 합니다.
  * 첫 구매 고객의 재구매 주기(중앙값 59일)에 맞춘 리텐션 트리거 캠페인이 필요합니다.

## 📁 디렉토리 구조

```text
olist-analysis/
├── docs/                     # GitHub Pages 배포용 웹 사이트
│   ├── index.html            # 인터랙티브 대시보드 (홈, 분포, 추이, 재구매 시점, 리뷰 원문, 생키 흐름)
│   ├── story.html            # 분석 케이스 스터디 상세 보고서
│   └── data/
│       ├── orders.js         # 전체 주문 조건별 경량 집계 데이터
│       └── reviews.js        # 고객 리뷰 원문 및 한국어 번역 데이터
├── results/                  # 분석 산출물
│   ├── 1_flow_late.png       # 배송 지연 흐름 시각화
│   ├── 2_repeat_by_review.png # 리뷰 평점별 재구매율 그래프
│   ├── 3_complaint_themes.png # 부정 리뷰 불만 카테고리 분포
│   ├── review_ko.json        # 번역된 포르투갈어 리뷰 샘플
│   └── summary.md            # 분석 통계 상세 요약표
├── analyze.py                # 가설 검증 및 통계 분석 실행 스크립트
├── build_explorer.py         # 웹 대시보드용 데이터 집계 생성 스크립트
├── translate_reviews.py      # 포르투갈어 리뷰 한글 번역 도구
├── requirements.txt          # 파이썬 의존성 패키지 목록
└── README.md
```

## 🛠️ 실행 방법

```bash
# 가상환경 생성 및 활성화
python3 -m venv .venv
source .venv/bin/activate

# 필수 라이브러리 설치
pip install -r requirements.txt

# 분석 실행 (결과물 및 그래프 생성)
python analyze.py

# 웹 대시보드 집계 데이터 생성
python build_explorer.py
```
