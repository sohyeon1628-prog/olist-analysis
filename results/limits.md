# 분석의 한계 (본인 확인용)

분석 이야기(story.html)에서 뺀 한계 정리. 결과를 설명하거나 면접에서 질문을 받을 때 이 범위를 넘어서 말하지 않는다.

## ① 결론으로 쓰지 않은 것

| 한계 | 왜 그런가 | 그래서 이렇게 읽는다 |
| --- | --- | --- |
| 관계일 뿐 원인은 아닙니다 | 지연과 부정 리뷰가 함께 나타난다는 관찰입니다. | 원인인지는 제안한 A/B 테스트로 확인해야 합니다(08). |
| "평점이 판매에 영향을 준다"는 전제는 확인되지 않았습니다 | 탐색에서 보인 관계가 검증 구간에서 뒷받침되지 않았습니다(07). Olist 별점은 만족도 설문이라 고객에게 보이는 값인지도 모릅니다. | 제안은 "불만을 줄이는 실험"까지입니다. 판매 효과는 자체 데이터와 실험으로 확인해야 합니다. |
| 재구매 차이는 작으면 잡아내지 못합니다 | 첫 구매 고객 5.5만 명 중 180일 안에 다시 산 사람은 1,080명(1.95%)뿐입니다. | "차이 없음"은 "영향이 전혀 없다"가 아니라 "있더라도 작다"입니다. 부정 vs 긍정은 p = 0.061로 기준(0.05)에 가까웠고 글을 남긴 고객만 보면 기준을 넘었지만(05), 미리 정한 규칙대로 결론은 "차이 없음"이고 05는 가설입니다. |
| "소비자가 Olist를 모른다"는 구조 설명은 가설입니다 | 리뷰에 Olist 언급이 0건이고 같은 판매자로 돌아오는 경우가 29%뿐이라는 데이터는 이 설명과 맞습니다. | 재구매가 드문 진짜 이유(구매 주기, 가격, 다른 채널)는 구분하지 못합니다. |
| 묶음 주문의 "나뉘어 도착"과 세일 시기도 가설입니다 | 분할 배송 여부가 데이터에 없고, 불만 글은 단어 사전으로 세어 놓치거나 잘못 잡은 글이 있습니다. | 세일 시기는 블랙프라이데이 한 번의 사례이고, 물량만으로는 설명되지 않는 달(2018-02·03)이 있습니다. |
| 판매자 지속은 판단을 보류합니다 | 탐색 구간에서 보인 관계가 검증 구간(293명)에서는 확인되지 않았습니다. | 판매자가 떠난 이유는 데이터에 없습니다. |

## ② 방법·데이터의 한계와 바로잡은 것

| 한계 | 왜 그런가 | 그래서 이렇게 읽는다 |
| --- | --- | --- |
| 감성 모델은 부정과 긍정 두 가지로만 나눕니다 | 칭찬과 불만이 섞인 글도 어느 한쪽으로 분류됩니다. 정확도를 잰 정답 세트(400건)도 Claude가 판정했습니다. | 사람이 50건을 따로 판정한 일치율(86.7%)을 함께 공개했습니다. |
| 단어 사전에 오류가 있었다 | "ma qualidade(나쁜 품질)"를 글자 단위로 찾아, 칭찬인 "ótima qualidade(아주 좋은 품질)"도 품질 주제에 걸렸다. 같은 이유로 "uma qualidade duvidosa", "baixíssima qualidade" 같은 실제 불만 표현도 걸렸다. | 부정 리뷰 412건 중 칭찬이 잘못 걸린 건 3건(2026-11-24 원 데이터로 재확인)이라, 빼도 409건(7.6%)으로 결론은 같다. 이전 문구의 "412 → 400건(7.4%)"은 실제 불만 9건까지 뺀 계산이라 오류를 과장했다. v1.2 결과는 그대로 둔다. |
| 사후 발견의 숫자를 한 번 바로잡았습니다 | 처음에는 Olist가 설문을 보낸 날짜를 기준으로 "받기 전 작성 76.5%"라고 적었습니다. | 고객이 실제로 답한 시각으로 다시 계산해 72.6%(부정 비율 82.1% vs 21.3%)로 고쳤습니다. 방향과 결론은 같습니다. 코드: posthoc_review_timing.py |
| 카테고리별 결론은 내리지 않았습니다 | 대부분 카테고리에서 지연 후 재구매 고객이 10명 미만이었습니다. | 카테고리별 차이는 결론으로 쓰지 않았습니다. |
| 2017~2018년 브라질 데이터입니다 | 배송 환경과 구매 습관이 다른 시장과 다릅니다. | 결과를 그대로 옮기기보다, 같은 방법을 자체 데이터에 다시 적용해야 합니다. |
