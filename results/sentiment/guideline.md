# 리뷰 글 감성 판정 기준 (평가용 정답 세트)

작성 2026-11-22 · 판정 전에 확정. 판정을 시작한 뒤에는 바꾸지 않는다.
이 분석은 계획서 v1.2에 없던 **탐색적 분석**이다.

## 목적
별점이 아니라 **글 내용만**으로 감성을 판정한 정답 세트를 만들어,
(1) 감성 모델(BERTimbau)의 실제 정확도를 재고, (2) 별점과 글이 어긋나는 비율을 잰다.

## 표본
- 대상: 글이 있는 Olist 리뷰 40,809건 (`docs/data/reviews.js`)
- 별점 1~5점마다 80건씩 무작위 추출 (seed 42) → 400건
- 판정 파일(`gold_texts.json`)에는 번호와 포르투갈어 원문만 있다. 순서는 섞는다.
  별점은 `gold_key.json`에 따로 두고, 판정이 끝날 때까지 열지 않는다.

## 판정 라벨 (글만 보고 하나 고름)
| 라벨 | 기준 | 예 |
| --- | --- | --- |
| **부정** | 불만·문제·실망만 있고 긍정 요소가 없다. 아직 못 받았다, 불량, 다른 상품, 누락, 늦음, 연락 없음, 환불 요구 등 | "não recebi o produto" |
| **혼합** | 긍정과 부정이 **둘 다** 분명히 있다 | "demorou, mas o produto é ótimo" |
| **중립** | 평가 없이 사실만 있다 | "recebi o produto", "ainda não usei" |
| **긍정** | 만족·칭찬·추천만 있고 불만이 없다 | "chegou antes do prazo, recomendo" |
| **판정 불가** | 의미 없는 글자, 판단할 수 없는 글 | "t4354t4t" |

### 세부 규칙
1. 글에 적힌 내용만 본다. 별점·번역·작성자 사정을 추측하지 않는다.
2. "아직 못 받았다/언제 오나"처럼 배송 상태를 묻는 글은 불만이 드러나지 않아도 **부정**.
3. 반어(비꼬기)는 뜻하는 바로 판정한다.
4. "~했으면 더 좋았겠다" 같은 가벼운 아쉬움 + 칭찬은 **혼합**.
5. 줄임말·오타(q=que, vc, td, nao)는 뜻을 살려 읽는다.

## 평가 방법 (미리 정함)
- 모델은 부정/긍정 두 가지로 학습한다 (B2W 별점 1~2 = 부정, 4~5 = 긍정, 3 제외).
- **정확도**: 정답이 부정 또는 긍정인 리뷰에서 모델 판정이 맞은 비율. 부정·긍정 각각의 재현율도 함께 보고한다.
- 혼합·중립은 정확도에서 빼고, 모델이 어느 쪽으로 판정했는지 비율만 보고한다.
- 판정 불가는 모든 계산에서 뺀다.
- **별점–글 불일치**: 별점 4~5 리뷰 중 정답이 부정인 비율, 별점 1~2 리뷰 중 정답이 긍정인 비율.

## 판정자와 확인
- 1차 판정: Claude (별점을 보지 않음).
- 확인: 박소현이 무작위 50건을 별점 없이 따로 판정 → 두 판정의 일치율을 공개한다.
