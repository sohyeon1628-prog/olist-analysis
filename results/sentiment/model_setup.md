# 감성 모델 학습 설정

작성 2026-11-22 · 학습 전에 확정 (탐색적 분석, 계획서 v1.2 밖)

## 학습 데이터: B2W-Reviews01 (Olist와 무관한 브라질 쇼핑몰 리뷰)
- 출처: github.com/americanas-tech/b2w-reviews01 (129,098건, 글 있는 리뷰)
- 정답: 별점 1~2 = 부정(0), 4~5 = 긍정(1), 3점 제외
- 같은 글은 하나만 사용
- 무작위(seed 42)로 학습 8,000건(부정 4,000 / 긍정 4,000), 검증 1,000건(500 / 500). 두 세트는 겹치지 않음
- 이 컴퓨터(Intel i5, GPU 없음)에서 끝낼 수 있게 B2W 일부만 사용

## 모델
- neuralmind/bert-base-portuguese-cased (BERTimbau base)
- 최대 128토큰, 배치 16, 1에폭, 학습률 2e-5 (앞 10% 워밍업 후 선형 감소), weight decay 0.01
- 길이가 비슷한 글끼리 배치를 묶어 계산량을 줄임 (결과에는 영향 없음)

## 판정 규칙
- 모델이 낸 긍정 확률 ≥ 0.5 → 긍정, 아니면 부정

## 보고할 것 (미리 정함)
1. B2W 검증 1,000건 정확도 (별점 기준 — 참고용)
2. **정답 세트 400건 기준 정확도** (`guideline.md`의 평가 방법) — 모델 실력은 이 숫자로만 말한다
3. Olist 글 리뷰 전체에 적용한 결과 (별점–글 불일치 비율, 첫 구매 고객의 글 감성별 재구매율)
