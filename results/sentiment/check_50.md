# 감성 판정 확인 (50건)

별점 없이 **글 내용만** 보고 판정해 주세요. 기준은 `guideline.md`와 같습니다.
- 부정: 불만·문제만 있음 (아직 못 받음, 불량, 누락, 늦음 등)
- 혼합: 칭찬과 불만이 둘 다 있음
- 중립: 평가 없이 사실만 있음
- 긍정: 만족·칭찬만 있음
- 불가: 무슨 말인지 판단할 수 없음

번역은 Azure 기계 번역이라 틀릴 수 있습니다. 이상하면 원문을 참고하세요.
각 항목의 `판정:` 뒤에 부정/혼합/중립/긍정/불가 중 하나를 적고 저장해 주세요.
